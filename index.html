02 / GET READY

예매 전 준비 순서

  1. 하루 전 또는 1~2시간 전

    공연 저장 → Chrome 확장에 설정 가져오기 → 예매 페이지 열기 → 화면 점검 및 버튼 지정 → 10분 전 자동 열기 예약.

  2. 시작 직전

    로그인·인증·팝업 허용을 확인하세요. 확장에서 시작 대기를 켜고 공연 탭을 열어두면 지정한 예매 버튼을 시작 시각 이후 한 번 누릅니다.

  3. 좌석과 결제 단계

    회차를 선택하고 좌석 후보를 확인하세요. 지원되는 좌석 구조에서만 연속 좌석을 클릭합니다. 지정한 다음 단계 버튼도 확인 후 클릭할 수 있습니다. 최종 결제는 직접 진행합니다.

링크 등록만으로 모든 사이트의 자동 예매가 지원되지는 않습니다. iframe·캔버스 좌석, 사이트별 보안 및 DOM 차이는 별도 연동이 필요합니다. 화면 점검 결과를 먼저 확인하세요.
