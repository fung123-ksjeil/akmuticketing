악뮤 예매 도우미

고양 킨텍스 · 2027. 1. 2. (토) 오후 5시

하루 전·2시간 전·1시간 전·시작 시각에 알립니다. Chrome이 실행 중이어야 하며 절전 시 지연될 수 있습니다.

자동 열기는 예스24 접근 권한을 승인한 후 작동합니다. 로그인 완료 표시를 지정하면 자동 감지하고, 지정하지 않으면 로그인 후 위 완료 버튼을 누르세요. 컴퓨터와 Chrome을 켜두어야 합니다.

1. 미리 화면 점검

실제 공연 페이지를 열고 점검하세요.

대기열·보안문자·회차 선택은 직접 진행합니다. 점검은 현재 화면만 읽으며 이후 단계의 지원을 보장하지 않습니다.

2. 예매 버튼 준비

대기는 현재 공연 페이지에만 적용됩니다. 페이지 새로고침·이동 시 해제되며, 컴퓨터·브라우저를 켜 두세요. 시작 후 버튼이 활성화되면 한 번만 클릭합니다. 2분 안에 활성화되지 않으면 종료합니다.

3. 연속 좌석 설정

좌석 DOM 어댑터가 필요합니다. 실제 속성 이름을 확인해 설정하세요. iframe·캔버스는 지원하지 않습니다.

같은 열·블록의 연속 번호만 선택합니다. 속성이 부족하면 중단합니다. 구역·무대 방향·통로는 실제 배치로 확인하세요.

예스24 진행 순서 · 고급 설정

1월 2일 → 17시 → 좌석 → 완료 → 다음 3단계 → 무통장입금 → 국민은행(없으면 선택 가능한 첫 은행) → 전체 동의 → 결제하기. 실제 입금은 직접 합니다. 실제 DOM 어댑터가 필요합니다.

한 줄에 CSS 선택자 하나. 예매 버튼 이후 순서대로 한 번씩 누릅니다. SEATS는 연속 좌석 클릭, WAIT 선택자는 해당 수동 화면이 사라질 때까지 대기합니다. 앞 단계가 완료되어 다음 버튼이 실제로 나타나야 재개합니다. 확인하지 않은 버튼을 입력하지 마세요. 화면 전환·새 창에서는 다시 준비해야 합니다.

실제 배치 좌표가 있는 어댑터에서만 인접 구역을 탐색합니다. 화면상의 버튼 위치나 구역 번호로 인접 관계를 추측하지 않습니다.

4. 다음 단계

결제 화면으로 이동하는 버튼까지 보조합니다. 일반 클릭에서는 최종 결제를 누르지 않습니다. 무통장 전용 순서는 결제하기로 예매를 신청합니다. 로그인·결제 정보는 읽거나 저장하지 않습니다.
